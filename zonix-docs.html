// WINDOW & TAB CREATION

🪟 Window

Create the main window container for your UI. Windows can be dragged, minimized, and closed. Supports emoji and image icons (emoji characters or rbxassetid).

LUA 
local Window = Zonix:Window({
    Name = "My Script Name",
    Icon = {
        Type = "image",
        Value = "rbxassetid://90642687165275"
    },
    MinimizeMode = "collapse", -- "collapse" or "shrink"
    CompactMode = false -- Start in compact mode (25% smaller)
})
Parameter Type Required Description
Name string ✗ The window title (default: "Zonix UI")
Icon table ✗ Icon configuration with Type ("emoji" or "image") and Value (emoji character or rbxassetid). Displays as 28x28px in topbar. Example: { Type = "emoji", Value = "🔥" }
MinimizeMode string ✗ Minimize behavior (default: "collapse"). Options: "collapse" (topbar only) or "shrink" (100x100 square)
CompactMode boolean ✗ Start in compact mode (default: false). Reduces UI size by 25% while maintaining all functionality

Window Features:

  • Draggable by clicking and holding the top bar
  • Minimize button (-) - Minimizes window based on MinimizeMode:
    • collapse - Collapses to topbar only (traditional)
    • shrink - Shrinks to small 100x100 square (compact)
  • Close button (x) - Destroys the window completely
  • Smooth animations for all interactions
  • Automatic shadow and glow effects
  • Emoji or image icon support (28x28 pixels, centered vertically)

🔍 Search

Advanced search component with 6 search modes, fuzzy matching using Levenshtein distance, intelligent result ranking, tag-based searching, HideNonMatching focus mode, CustomSearch for workspace/players, and extensive customization options. Perfect for searching through UI elements with precision and flexibility.

LUA 
local MySearch = Tab:Search({
    Placeholder = "Search UI elements...",
    DefaultMode = "contains",
    ShowModeSelector = true,
    LiveSearch = true,
    CaseSensitive = false,
    SaveHistory = true,
    MaxHistorySize = 10,
    ShowResultCount = true,
    ClearButton = true,
    SearchDelay = 0.3,
    HighlightColor = Color3.fromRGB(88, 101, 242),
    FuzzyThreshold = 0.6,
    MaxResults = 100,
    SearchInTags = true,
    HideNonMatching = false, -- Focus mode
    Position = "order", -- "top", "bottom", or "order"
    CustomSearch = nil, -- Custom search function
    Callback = function(query, results, search) -- NEW: 'search' param!
        print("Mode:", search:GetMode())
        print("Found", #results, "results")
    end
})

-- Switch search modes
MySearch:SetMode("fuzzy")

-- Add tags for better searchability
MySearch:AddElementTag("Speed Slider", "movement")

Search Modes:

  • 🔍 Contains - Finds text anywhere in element (default, fast performance)
  • 🎯 Exact - Exact text match only (most precise, no partial matches)
  • ▶️ Starts With - Matches text at the beginning of element name
  • ◀️ Ends With - Matches text at the end of element name
  • ✨ Fuzzy - Approximate matching using Levenshtein distance algorithm (typo-tolerant)
  • 🔧 Regex - Pattern matching with regular expressions (most powerful and flexible)
Parameter Type Required Description
Placeholder string ✗ Placeholder text (default: "Search UI elements...")
DefaultMode string ✗ Starting search mode (default: "contains")
ShowModeSelector boolean ✗ Show mode dropdown selector (default: true)
LiveSearch boolean ✗ Search as you type (default: true)
CaseSensitive boolean ✗ Enable case-sensitive search (default: false)
SaveHistory boolean ✗ Auto-save search history (default: true)
MaxHistorySize number ✗ Maximum history items (default: 10)
ShowResultCount boolean ✗ Display result count with mode indicator (default: true)
ClearButton boolean ✗ Show clear button (default: true)

HighlightColor Color3 ✗ Result highlight color (intensity varies by score)
FuzzyThreshold number ✗ Fuzzy match threshold 0-1 (default: 0.6, lower = more lenient)
MaxResults number ✗ Maximum results to display (default: 100)
SearchInTags boolean ✗ Enable searching in element tags (default: true)
HideNonMatching boolean ✗ Hide non-matching elements while searching (focus mode, default: false)
Position string ✗ Search bar position: "top", "bottom", or "order" (default: "order")
CustomSearch function ✗ Custom search function(query, mode) → results[] for workspace/players/custom data

Example: CustomSearch - Workspace Parts

LUA 
-- Search for parts in workspace instead of UI
local PartSearch = Tab:Search({
    Placeholder = "Search workspace parts...",
    Position = "top",
    CustomSearch = function(query, mode)
        local results = {}
        local searchQuery = query:lower()
        
        for _, part in pairs(workspace:GetDescendants()) do
            if part:IsA("BasePart") then
                local name = part.Name:lower()
                
                if name:find(searchQuery, 1, true) then
                    table.insert(results, {
                        Name = part.Name,
                        Object = part,
                        Position = part.Position,
                        Score = 1
                    })
                end
            end
        end
        
        return results
    end,
    Callback = function(query, results)
        print("Found", #results, "parts")
        for _, result in ipairs(results) do
            print("Part:", result.Name, "at", result.Position)
        end
    end
})

Example: CustomSearch - Players

LUA 
-- Search for players in the game
local PlayerSearch = Tab:Search({
    Placeholder = "Search players...",
    Position = "top",
    CustomSearch = function(query, mode)
        local results = {}
        local searchQuery = query:lower()
        
        for _, player in pairs(game.Players:GetPlayers()) do
            local name = player.Name:lower()
            local displayName = player.DisplayName:lower()
            
            if name:find(searchQuery, 1, true) or 
               displayName:find(searchQuery, 1, true) then
                table.insert(results, {
                    Name = player.Name,
                    DisplayName = player.DisplayName,
                    Player = player,
                    Score = 1
                })
            end
        end
        
        return results
    end,
    Callback = function(query, results)
        if #results > 0 then
            print("Found players:")
            for _, result in ipairs(results) do
                print("- " .. result.Name)
            end
        end
    end
})

➡️ In-line Layout

Place GroupBoxes side-by-side instead of stacking vertically.

LUA 
-- Start inline layout
local inline = Tab:StartInline()

-- Add GroupBoxes that will appear side-by-side
local SpeedGroup = Tab:GroupBox({
    Name = "Speed Settings",
    Inline = true
})

local FarmGroup = Tab:GroupBox({
    Name = "Farming Settings",
    Inline = true
})

-- Stop inline layout
inline.Stop()

-- Elements below will stack normally
Tab:Button({
    Name = "Apply Settings"
})

How it Works:

  1. Call Tab:StartInline() to begin horizontal layout
  2. Add GroupBoxes with Inline = true (they'll appear side-by-side)
  3. Call inline.Stop() to return to normal vertical stacking

Best Practices:

  • Use for grouping related controls (e.g., Speed section next to Farming section)
  • Limit to 2 inline groups for optimal mobile compatibility
  • Always call .Stop() to prevent layout issues
  • Each inline GroupBox takes 48% width, leaving 4% for spacing

🏷️ Flag System

Global value storage accessible from anywhere in your script.

LUA - FLAG USAGE 
Tab:Toggle({
    Name = "Auto Farm",
    Flag = "AutoFarm"
})

Tab:Slider({
    Name = "Speed",
    Flag = "Speed"
})

while true do
    if Zonix.Flags.AutoFarm then
        local speed = Zonix.Flags.Speed or 50
    end
    wait(1)
end

How Flags Work:

  • Any component with a Flag parameter stores its value in Zonix.Flags
  • Access via: Zonix.Flags.YourFlagName
  • Values update automatically when component changes
  • Flags persist through config save/load
  • Use flags instead of storing component references

Supported Components:

  • Toggle: stores boolean value
  • Slider: stores number value
  • Dropdown: stores string value
  • Textbox: stores string value
  • Keybind: stores Enum.KeyCode value
  • ColorPicker: stores Color3 value
💡 TIP: Use flags to access component values from anywhere without storing component references!

Q: Which executor is best?
A: Zonix UI works on ALL executors. Choose based on your needs, platform, and preferences.
Q: Does clipboard work on all executors?
A: Zonix UI tries multiple clipboard function names and works on most executors with automatic fallbacks.

A: Use Zonix:SaveConfig("name") to save and Zonix:LoadConfig("name") to load configurations.
Q: Can I use multiple windows?
A: Yes! Create multiple windows with different names and they'll work independently.
Q: How do I access component values?
A: Use flags! Set a Flag parameter on components and access via Zonix.Flags.YourFlag
Q: Will this get me banned?
A: Using any exploit carries risk. Zonix UI itself won't get you banned, but the scripts you run might. Always use on alt accounts.
Q: How do I update the library?
A: Simply reload the script with the latest version from hub.zon.su. Your configs will be preserved if using the same config names.
Q: Can I customize the UI colors?
A: Yes! Create custom themes by defining all 13 color properties in Zonix.Themes.YourTheme
Q: How do I hide/show the UI?
A: Use a keybind component to toggle visibility, or manually destroy the window via the close button (×)
